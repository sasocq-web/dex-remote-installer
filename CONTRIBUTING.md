# Como contribuir

1. Faça as alterações em uma branch separada.
2. Execute `./build.sh`.
3. Execute `./tests/test-package.sh`.
4. Descreva no pull request o fluxo real testado e os riscos de regressão.

Mudanças no perfil completo precisam preservar a separação entre `codex` e
`codex-worker`. Nenhuma contribuição pode adicionar credenciais, contas,
conversas, chaves ou dados de uma instalação de origem.
